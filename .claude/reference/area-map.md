## How the code is layered (one line)

`web/` → `services/` and `agent/` → pure core (`domain/`, `policy/`, `gates/`, `checks.py`, `privacy/`) and `ports/`;
external adapters implement `ports/`; storage is a `UnitOfWork` port over concrete SQLite repositories; `web/container.py`
is the only place that wires concretes. Detail: DO-3 §2.

## Areas and waves

**Critical path:** A0 → A7a → A7b / A7c / A7d (A10b also in wave 3). **Shared files** and how collisions are avoided: DO-3 §8 collision map.
**Repo stubs:** `repos_cases.py` is A0's whole (AEA-10, slice plan §0). The other five `repos_<area>.py` are A0 stubs after wave 0, then
its body belongs to the owning area in the table above (spend A2, identity A4, booking A5, staff A9, ops A10a). Every `schema/*.sql` is
written by A0 (AEA-10). `db.py` and `ports/runtime.py` stay frozen.
**Screens** are the React 19 + Vite + TypeScript + Tailwind + shadcn/ui app `apps/web/` (UX-4 prototype, **built 2026-10-21; UX-4 gate not yet signed**; it replaces the earlier server-rendered `web/templates` + `web/static` plan). A8 and A9 are API only (no templates, static files or Jinja pages); `jinja2` is therefore no longer needed and is **droppable** from `pyproject.toml` (not edited here). AEA-49 (`web/frontend.py`, A8) serves the built `apps/web/dist` with a fallback to `index.html` (**built**, AEA-49 `49ba7ff`); A12's image needs a Node build stage with `docs/ux/03-structure/ui-contracts.openapi.yaml` in the build context (**planned**). Route files are split one per ticket, each with its own schema file: ten in all, `routes/{auth,chat,events,handoff,demo,reads}.py` and `routes/staff_{session,cases,live,clock}.py` (AEA-23, 40, 41, 42, 43, 48 and 44, 45, 46, 47), per [slice plan](../../docs/plans/slice-plan.md) §0 and §3 (AEA-08, 2026-10-21).
