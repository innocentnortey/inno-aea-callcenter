## For Innocent

### GRC-3: When a representative owns the chat, does a safety message still get the safety instruction?

**The story.** A customer, Dana, asked for a person. Riley (the demo representative) claimed the case, so the chat is
now Riley's. While Riley types, Dana writes: "the CO alarm just went off". Today the design checks "is a person in
charge?" before it checks for safety words. So the message only goes to Riley's screen, and the AI says nothing. If
Riley is slow to read it, Dana waits with an alarm going off and no instruction. The PRD's R-5 says the safety check
"runs first on every turn". But DO-4 §3, the PRD's own flow diagram (line 306) and the system design (line 224) all put
"AI paused" first. So the sources disagree, and the choice decides what a customer in danger sees during a live chat.
It costs nothing to change before AEA-12 is built: the order is one line of code.

**Option A: safety first, then paused (recommended).** For gas, CO alarm, sparks/smoke/flames, or burning smell with
tripped breakers, the AI shows the fixed KB safety card in the same turn. The message still reaches Riley, and Riley
stays in charge of the chat. Everything else (questions, the burning-smell question, danger words) goes only to Riley.
*Gain:* R-5 holds literally; the instruction is fixed text, no model, so it can't contradict Riley. *Give up:* the
customer sees one automated card inside a human conversation.

**Option B: paused first, as DO-4 has it.** Riley sees the message and decides what to say. *Gain:* one voice in the
chat. *Give up:* the safety instruction depends on how fast a person reads; R-5's "every turn" is not met.

**Option C: all code-only safety gates first** (safety, the burning-smell question, danger words), then paused.
*Gain:* the most protective. *Give up:* the AI can start asking the R-7 question in Riley's chat, which can confuse
both of them.

*Recommended: A.* It is the only option that meets R-5 as written, without the AI talking over the representative
about anything other than an emergency.

**Decision needed:** While a representative owns the chat, should a safety message get the AI's safety instruction
(A), go only to the representative (B), or should every code-only safety gate run first (C)?

Until he answers, AEA-12 builds A (one tuple in `gates/gate.py`, with a test for each order).
